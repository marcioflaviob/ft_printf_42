# ft_printf

Recreating the function printf from stdio.h in C

## Installation

```bash
git clone https://github.com/marcioflaviob/ft_printf_42.git && cd ft_printf_42
```

## Usage

```bash
make
```

This will compile everything for ft_printf then include ft_printf's header in your project.

```c
import "path/to/ft_printf.h"

// Same usage as printf, but writing ft_printf();
```

Compiling your file:

```bash
cc -Wall -Wextra -Werror your_file.c libftprintf.a
```
